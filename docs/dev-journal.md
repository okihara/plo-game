# 開発日誌（週次ジャーナル）

BabyPLO（PLOポーカーゲーム）の開発記録。git履歴（2026-01-15 初コミット〜）を週単位でまとめたもの。
各週は月曜始まり。コミット数は目安。

---

## 2026-01-12週（1/15〜1/18）— プロジェクト誕生

初コミット。Vanilla JSでPLOゲームの原型を作り、わずか3日後にReact + Tailwind CSSへ移行。

- PLOゲームエンジンの基礎、ディーラーボタン、フォールド後の自動進行
- カード配布アニメーション、コミュニティカードのフリップ演出
- プリフロップハンド強度インジケーター、エクイティ・アウツ表示のハンド分析オーバーレイ
- CPU対戦（思考時間 400〜1000ms）

## 2026-01-19週 — 小休止

- プリフロップ評価ロジックの精緻化のみ（1コミット）

## 2026-01-26週（〜2/1）— オンラインマルチプレイヤーの誕生

この週が最大の転換点。ポットリミット対応を固めた後、Fastify + Socket.io のサーバーを一気に構築。

- ベットスライダーのポットリミット制約、プリセットボタンの正確なレイズ額計算
- 9:16縦画面レイアウト導入（後の全UIの基盤）、CPUアバターとポップカラーテーマ
- **オンラインマルチプレイヤー基盤**（TableInstance、FastFold、管理ダッシュボード、Botの別プロセス化）
- オフラインモードを削除しオンライン専用に集約
- アクションタイマー（円形プログレスリング）、切断時のゲーム進行修正
- FastFoldPool → MatchmakingPool へ改名、ブラインド選択ロビー
- CSSコンテナクエリ（cqw単位）への統一開始

## 2026-02-02週 — 認証と本番デプロイ

- **Twitter OAuth認証**を導入（Google/Discordは削除）、プロフィール画像連携
- **Railwayへ本番デプロイ**（trustProxy、prisma db push、Redis依存を削除）
- ダークテーマ化、チップベットアニメーション
- TableInstanceをモジュラーなヘルパークラス群へリファクタリング

## 2026-02-09週（2/13〜2/15）— Bot AI大改修と記録系の土台

- **Bot AIをモジュラーアーキテクチャに全面刷新**（パーソナリティ、戦略分岐）
- **ハンド履歴の保存・閲覧UI**、**プレイヤースタッツ**（VPIP/PFR/3Bet/CBet等）
- サイドポット計算とポット分配の是正
- ゲームペーシング調整、Twitter OAuthを1.0aへ移行

## 2026-02-16週 — 「Baby PLO」命名と怒涛の作り込み（週150コミット超）

シリーズ最多ペースの週。UIデザイン・演出・安定性を総ざらい。

- タイトルを「Baby PLO」に決定、ロビーにマスコット画像
- ショウダウン演出の段階化（カードreveal→WIN表示）、3Dフリップ公開
- 白黒デザイン→グラスモーフィズム→ウォームクリーム/ライトテーマと試行錯誤
- ログインボーナス（JST 7:00リセット）、メンテナンスモード、ゲスト接続の完全無効化
- gameEngineのユニットテスト導入（Vitest、71テスト）+ GitHub Actions CI
- 30秒grace period廃止→即unseat、フルレイズルール（リオープン制限）実装
- **FastFoldモード本実装**（早期フォールドで次テーブルへ）、Bot 20体化
- アクション効果音（ElevenLabs TTS）、favicon、OGPメタデータ
- 買い占め防止のuncalled bet返却、レースコンディション多数修正

## 2026-02-23週（〜3/1）— スタッツ深化とモノレポ化

- **オールインEV収支の計算・トラッキング**（グラフのEVライン、4Betスタッツ、ランキングポップアップ）
- **レーキシステム**（ポット5%・3BBキャップ・no flop no drop）
- デイリー/ウィークリーリーダーボード、ロビーのミニランキング
- 名前マスク・Twitterアバターopt-inのプライバシー設定（マスク処理をサーバー側へ）
- **pnpm workspacesモノレポへ移行**（@plo/shared パッケージ新設）
- 切断フォールドをapplyAction経由に統一しフリーズ根絶、TableInstanceテスト大量追加
- Bot 100体化、リバーコール頻度の引き締め、river nuts分析
- プロフィール編集（表示名・アバター）、**バッジ/実績システム**の第一弾
- プライベートテーブル（招待コード）を試験導入

## 2026-03-02週（〜3/8）— マルチバリアントへの挑戦

- 同一ユーザーの複数タブ接続を排除（connection:displaced）
- ポーカールーム比喩ドキュメント（オンボーディング用）
- **7-Card Stud実装**（bring-in、エッジケーステスト群）→ **Razz** → **2-7 Triple Draw**とバリアント連打
- VariantAdapterヘルパーでTableInstanceの分岐を整理
- Bot AIの大規模バグ修正週間: ナッツ分析の脅威チェック、リバーワンペア100%フォールド問題、ドンクベット抑制、ツーペア過大評価
- バッドビートバッジ（fullhouse/quads/straight_flush）+ 遡及付与スクリプト
- 背景画像をWebP化（96%削減）

## 2026-03-09週（〜3/15）— HORSEとシェア機能

- **Limit Hold'em追加**、VariantConfigで判定を属性ベースに統一
- **HORSEミックスゲームテーブル**（バリアント変更通知の演出付き）
- **スタッツページのOGP画像生成・Xシェア**、ハンド履歴のOGPシェア
- validActionsをクライアントに送りボタン制御をサーバー基準に
- ボットのオープンリンプ排除（レイズorフォールド戦略）
- スペクテーターモードを一旦削除

## 2026-03-16週（〜3/22）— プリフロップ評価の科学化

- **プリフロップ評価をモンテカルロエクイティベースに刷新**（プレイアビリティ補正、ダングラー判定）
- TableInstanceからキャッシュゲーム固有ロジックを分離（トーナメント拡張の土台）
- PokerStars形式のハンド履歴コピー機能
- プレイヤーカラーラベル機能

## 2026-03-23週（〜3/29）— MTT（トーナメント）実装

設計書だけ存在していたMTTがついに実体化。以後数ヶ月の主軸となる。

- **MTT本実装**: TournamentManager、ブラインドスケジュール、テーブルバランシング、リエントリー
- バグ修正ラッシュ（5個→6個→…と連続的に潰し込み）
- OnlineGameをGameTable・NormalGame・TournamentGameへ責務分離
- 週間チャンピオン表示、歴代チャンピオン一覧
- 公開ハンドページを署名トークン方式のプライバシー保護に
- 管理ダッシュボードにトーナメント管理・キック・強制フォールドAPI
- BlindSchedulerをタイマー廃止・経過時間ベースに刷新

## 2026-03-30週（〜4/5）— トーナメント磨き込みとアプリ風UI

- ハンド二重起動防止、chaosMode（Botのランダム切断テスト）
- **縦向きベットスライダー**（グリップ付き大型ハンドル、オレンジ配色）
- トーナメントクロックパネル・HUD、結果ページのポディアムデザイン
- **テーブル観戦（spectate）機能**を正式実装（席単位ホールカード送信）
- **ボトムナビゲーション導入**でロビーをアプリライクなタブUIに
- デイリーPLOクイズの自動生成・Twitter投稿スクリプト
- OnlineConnectionGate（接続エラー・タブ退避のオーバーレイ化）

## 2026-04-06週（〜4/12）— 安定化とランキング整備

## 全体の流れ（俯瞰）

1. **1月**: ローカルPLOゲームの原型 → React化 → オンライン化
2. **2月**: 認証・本番デプロイ・FastFold・スタッツ/履歴・レーキと「ポーカーサイトの体裁」を確立
3. **3月**: バリアント拡張（Stud/Razz/Draw/HORSE）→ モンテカルロ評価 → **MTT実装**
4. **4月**: トーナメント磨き込み、AIレビュー、X運用の半自動化、RPランキング
5. **5月**: PLO5/DBBP/PLO8/Big-Oの種目拡充、ドメイン移行、Sentry、自動再接続、ゲストトナメ
6. **6月**: パフォーマンス対策（worker offload）、PLO6、シーズン制
7. **7月**: 運用自動化の仕上げとDBクエリ最適化
