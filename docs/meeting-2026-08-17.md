# 打ち合わせメモ（2026-08-17）

Bot 改善・HUD 拡張・コミュニティ運営についての打ち合わせ記録。

### ボット改善の方向性

- 現在のボットの実装は「自分のハンド単体のエクイティのみ」を見ており、相手のアクションによってレンジが絞られるという概念が弱い
- 改善アプローチは大きく2種類
    - **ルールベース（優先）**: 全パターンをプログラムする方法。まず着手しやすい
    - **機械学習（将来）**: ソルバーデータ等を学習させてブラックボックス的に動かす方法。時間・データ・知識が必要
- ルールベースでは「ボードテクスチャ × ハンドの強さ × 相手のアクション」をポイント形式でスコアリングし、閾値を超えたらアクションを決める方式が現実的
- プリフロップはすでに改善済み（VPIP 6.0前後、均衡に近い数値）

### ポストフロップ戦略の言語化

- 相手がベットやチェックレイズをした際に、**自分のハンドエクイティがどれだけ変化するか**をボットが認識する必要がある
- 例：マルチウェイでQ88ボード、Kings（KKxx）を持っている場合
    - UTGにACsレンジが存在するため、KingsはセカンドナッツでもEQは約33%程度
    - 1/3ベットしてコールされるとEQが25%程度まで低下
    - ターンで6スペードが落ちると、勝っていたハンドの多くがまくられる
    - → ドライかつドローが濃いボードほど、ベットしてコールされた際のEQ低下が激しい
- ボードテクスチャの簡易分類案（1〜13の数値より実用的）
    - カードのH/M/L（ハイ・ミドル・ロー）
    - モノトーン / ツートーン / レインボー
    - ストレート完成 / 未完成
    - ペアボード / コネクトボード / トリップスボード
- 相手のドンクベットやコールに対してレンジの濃度が変化するという概念をボットが計算できる仕様が理想
- ブロッカーの有無によってベットサイズを変える応用も将来的に検討

### HUD統計（ハード）の追加要望

- 現在の指標に加えて以下の追加を依頼
    - **ドンクベット率**
    - **チェックレイズ率**
    - **BMCB**（Bet to Misfit Continuation Bet：オリジナルレーザーがチェックした後のインポジション側のベット）
- これらをタップせず常時表示できる形にしてほしい
- コーチングの際に生徒に常時見せてプレーの指南に活用したい

### 機械学習・Sharp分析の可能性

- ソルバー出力をAIに学習させ、ボット判断のコードに変換することは原理的には可能
- ただしソルバー以上の強さを実現するには別の段階が必要
- 自己学習型ボット（経験を蓄積し期待値が高いアクションを自主的に選ぶ）も実現可能
    - 特定のフィールドには強くなるが、未経験の相手（ハイレートなど）には最初は弱い可能性あり
- **Sharp分析**：ポーカースポットのアクション分岐を数値化するフレームワーク。これをAIに分析させてポイント式に落とし込む活用を検討中
    - 座学の効率を大幅に改善できる可能性がある
    - Masataka Okiharaに内容を共有・説明予定

### 機能追加リクエスト（開発）

- **一時停止ボタン**
    - 権限を持つコーチがストップを押すと、そのハンド終了後に自動一時停止
    - 波動（HUD）追加より実装は容易な見込み
- **Win Rate表示**
    - テーブル開設からの累積成績を表示
    - プレイヤーのモチベーション管理に有効
- **Discordサーバー作成**
    - ユーザーがシステム問題を報告、プレイ募集などに活用
    - 9月目処
- **自動100BBバイイン**
    - 優先度は「停止ボタン＞HUD＞100BB」

- ポーカー界隈の「叩かれるから言いたくない」雰囲気の問題点を共有。オープンな文化にすることでPLO人口増加・レベル向上につながるという認識
